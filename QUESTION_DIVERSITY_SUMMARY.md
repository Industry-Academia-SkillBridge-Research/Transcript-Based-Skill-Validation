## How It Works

### Prompt Enhancement
```
QUESTION DIVERSITY REQUIREMENT:
- Do NOT repeat question types. Mix different question formats:
  * Definition questions: "What is X?"
  * Scenario-based questions: "In a situation where..."
  * Application questions: "How would you apply X to..."
  * Comparison questions: "What is the difference between X and Y?"
```

### Duplicate Detection Flow
```
1. Questions generated by Gemini
   ↓
2. TF-IDF vectorization (lowercase, stop words removed, ngrams)
   ↓
3. Pairwise cosine similarity calculation
   ↓
4. Flag questions with similarity ≥ 0.85
   ↓
5. Remove duplicates (keep first occurrence)
   ↓
6. Return unique questions + warnings
```

## Example

**Input:**
- Q1: "What is SQL?"
- Q2: "What does SQL mean?" (similarity: 0.92)
- Q3: "How do you write a SELECT query?"

**Output:**
- Q1: "What is SQL?" ✅
- Q3: "How do you write a SELECT query?" ✅
- Warning: "Removed 1 duplicate question(s)"

## Configuration

### Similarity Threshold
- **Default**: 0.85 (85% similarity = duplicate)
- **Adjustable**: Change in `check_duplicate_questions()` calls

### TF-IDF Settings
- Lowercase: Yes
- Stop words: English
- N-grams: Unigrams and bigrams (1, 2)
- Max features: 500

## Performance

- **Time**: < 1 second for 10-20 questions
- **Memory**: Minimal
- **Complexity**: O(n²) for n questions (pairwise comparison)

## Dependencies

- `sklearn` (scikit-learn) for TF-IDF and cosine similarity
- Gracefully falls back if sklearn not available
